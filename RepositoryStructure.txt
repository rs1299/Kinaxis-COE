Kinaxis-COE — Workspace Structure
=================================
Last refreshed: 2026-08-18

This is a TWO-TIER workspace:

  Kinaxis-COE/            PRIVATE working container (own git repo; NOT shared).
                         Holds individual/scratch work and generated outputs.
                         Does NOT track the nested shared repo (see .gitignore).

  Kinaxis-COE/npi_solutions/   SHARED team repo (own git repo; published to BitBucket).
                         Source of truth for standards, architecture, methodology,
                         accelerators, skills, tools, and shareable product projects.

The VS Code multi-root workspace (Kinaxis-COE.code-workspace) exposes exactly two
roots: the private container (".") and the shared repo ("npi_solutions").
