# Kinaxis-COE

Team repository for Maestro / RapidResponse solution authoring standards, architecture patterns, reusable accelerators, code tools, project artifacts, and governance evidence.

## Repository principles

1. Shared standards are the source of truth.
2. Product projects reference shared standards instead of duplicating them.
3. Code tools live under 	ools/ and should be reusable across projects.
4. Markdown artifacts should be version controlled and pull-request reviewed.
5. Generated outputs should be separated from source artifacts.
6. Testing evidence should be retained with releases.
