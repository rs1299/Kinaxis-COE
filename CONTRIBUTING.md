# Contributing

## Branching

Use feature branches:

`	ext
feature/<short-description>
fix/<short-description>
docs/<short-description>
standards/<short-description>
`

## Pull request expectations

Every pull request should identify:

- Purpose of the change
- Affected standards, projects, or tools
- Test evidence or review evidence
- Backward compatibility considerations
- Related ADRs, issues, or change requests

## Standards change rule

Changes under standards/ should be reviewed by the agreed standards owners before broad adoption.
